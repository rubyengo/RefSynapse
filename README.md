# RefSynapse

**Русский** · [English](#english)

Портативная доска референсов для Windows в духе PureRef — с ИИ-ассистентом, который умеет работать с доской.
A portable PureRef-style reference board for Windows — with an AI assistant that can work the board.

---

## Русский

### Возможности
- **Бесконечная доска**: изображения, видео, PDF, текст, рамки и группы; 3D-модели (в т.ч. FBX).
- **Навигация**: панорама (Space+ЛКМ), зум колесом, миникарта (Ctrl+M), поиск (Ctrl+F).
- **Инструменты**: пипетка (I), заливка (Shift+I), рисование маркером (удерживай D), трансформации G/R/S.
- **Видео**: клик или Space — play/pause, M — звук.
- **Надёжность**: автосохранение и восстановление после сбоя, история undo/redo.
- **ИИ-ассистент** (Ctrl+J): локальные и облачные модели, 22 инструмента доски, понимание картинок (vision), внешние инструменты через MCP.
- **Портативность**: работает с портативным Python, ничего не устанавливает в систему.

### Запуск (Windows 10/11)
1. Распакуй RefSynapse так, чтобы внутри лежала папка `python\` с портативным Python.
2. Запусти **«Запустить RefSynapse.bat»**. При первом старте он сам поставит зависимости из `requirements.txt` (нужен интернет, это занимает несколько минут).

Вручную из PowerShell:

    & ".\python\python.exe" -m pip install -r requirements.txt
    & ".\python\python.exe" RefSynapse.py

Для embeddable Python: в файле `python*._pth` раскомментируй `import site` и добавь строку `..`.

### ИИ-ассистент
Открой чат — **Ctrl+J**, настройки — кнопка в панели.
- **Провайдер**: любой OpenAI-совместимый сервер. По умолчанию — локальный LM Studio (`http://127.0.0.1:1234/v1`). Нужна модель с поддержкой tool calls; для описания картинок — vision-модель.
- **Инструменты доски**: ассистент добавляет, двигает и группирует элементы, делает превью. Удаление — только через подтверждение Yes/No (по умолчанию No).
- **MCP**: можно подключить внешние MCP-серверы (stdio или HTTP). Каждый вызов подтверждается по умолчанию; пустой список серверов = ноль внешнего доступа. Помни: MCP-сервер — обычная программа с правами твоего пользователя.
- **Ключ API** шифруется средствами Windows (DPAPI) и привязан к пользователю и ПК. На другом компьютере ключ нужно ввести заново.

| Клавиши | Действие |
|---|---|
| I | Пипетка |
| Shift+I | Заливка |
| D (удерживать) | Рисование |
| T / F | Текст / рамка |
| G / R / S | Перемещение / поворот / масштаб |
| Space + ЛКМ | Панорама |
| Колесо | Зум |
| Esc / ПКМ | Отменить инструмент |
| Ctrl+L | Заблокировать элемент |
| Ctrl+M | Миникарта |
| Ctrl+F | Поиск |
| Space / клик по видео | Видео: play/pause |
| M | Видео: звук вкл/выкл |
| Ctrl+J | ИИ-чат |
| F1 | Справка |
