# Хендовер: RefSynapse — перевод PDF (движок v9c, остались 2 дефекта)

## Несменяемые правила
- Перевод PDF ВСЕГДА mirror (с сохранением вида), молча: без вопросов о режимах.
- Mirror НИКОГДА не добавляет страниц. Не удалось точечное удаление → полная очистка
  и перерисовка; не удалось и это → оригинал + строка в отчёте.
- Проверочные скрипты — в dev; agent — только файлы агента (песочница).
- Команды из корня репо, пути относительные, питон — python\python.exe.
- Один шаг = одна команда PowerShell + ожидаемый вывод; объяснять простыми словами.
- Правки движка — сборщиком в dev (якорные замены + бэкап + compile), не пересылкой файла.
- Код целыми файлами; большие — отдельным сообщением. Коммит только по команде.

## Осталось 2 дефекта (чинить по одному, каждый со своим guard'ом)
### A. Текст заходит на фото: стр. 5 (SSD Intel), 9 (гибрид, плата PCIe), 11 (Blade, SATADOM)
Все случаи — абзацы, ОБТЕКАЮЩИЕ картинку: узкие строки слева, широкие под фото.
Гипотеза: _avoid_for исключает картинку из препятствий, если ХОТЯ БЫ ОДНА строка блока
задела её на 1 pt (нижние широкие строки касаются нижнего края фото) → препятствие снято.
Возможное лечение: требовать существенного пересечения (ширина > 8 pt и высота > 0.5*size),
либо переменная ширина строк (настоящее обтекание) в _fit_block.

### B. Наложение кусков внутри строки: стр. 8 («цены и ёмкости»), 16 («AnandTech»)
Гипотезы: (1) под русским остался английский — точечное удаление промахнулось;
(2) цветовая разбивка (_line_fragments / сдвиг x в _draw_blocks) рисует куски внахлёст.
Диагностика: снять spans результата в этой зоне — есть ли латиница под кириллицей,
и сколько раз рисуется один и тот же кусок.

## Ловушки (все проверены на себе)
- Открытое приложение держит старый движок в памяти → после правок ОБЯЗАТЕЛЕН перезапуск.
- Без restart:true инструмент продолжит старый job и перерисует старые (кривые) переводы;
  заслон v9c проверяет только НОВЫЕ переводы, сохранённые ранее — нет.
- Новое имя файла на диске ≠ новый job, если на доске документ со старым путём:
  надёжнее переименовать папку job в agent\translate.
- Якорь сборщика не должен содержать кавычку там, где в файле строка склеена (урок v9c:
  ANCHOR 12 FOUND 0). Брать короткий якорь без кавычек, проверять count == 1.
- extract_text в памяти ≠ после save+load (pypdf 7.1.0): проверки только на сохранённом файле.
- Консоль бьёт кириллицу: код и логи передавать ФАЙЛАМИ, не текстом; PYTHONIOENCODING=utf-8.
- Системный python — заглушка Windows, только python\python.exe.
- '%' перед '.' или пробелом в описании инструмента ломает регистрацию.
- Модель сдвигает переводы по списку id — это причина «текст не на своём месте», не геометрия.
- Отчёты ассистента могут врать в цифрах; верить только диагностике.
